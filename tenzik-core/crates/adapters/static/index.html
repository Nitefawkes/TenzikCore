About Tenzik Receipt Explorer

The Receipt Explorer provides a simple web interface for viewing and verifying execution receipts generated by Tenzik WASM capsules.

Features

  • 📋 View recent execution receipts
  • 🔐 Verify cryptographic signatures (Ed25519)
  • ✨ Check ZK proof status and verification
  • 📊 Inspect execution metrics (gas, memory, duration)
  • 🔍 Search and filter receipts

Receipt Components

Receipt ID
Unique identifier derived from capsule hash and execution context
Signature
Ed25519 signature over receipt contents using node's signing key
ZK Proof (Optional)
Zero-knowledge proof generated asynchronously for verifiable computation
Execution Metrics
Gas used, memory consumed, execution duration, capsule size

API Endpoints

  • GET /explorer - This web interface
  • GET /api/receipts - List recent receipts
  • GET /api/receipts/:id - Get specific receipt
  • POST /api/verify - Verify receipt signature
  • GET /proof/:job_id - Check proof status
